# Passo a Passo: Instalar LG webOS SDK e Deploy na TV\n\n## PARTE 1: Instalar o LG webOS SDK CLI\n\n### Windows\n\n1. **Abra o PowerShell como Administrador**\n   - Clique no ícone do Windows\n   - Digite: PowerShell\n   - Clique com botão direito > Executar como administrador\n\n2. **Instale o npm globalmente (se ainda não tiver)**\n   ```powershell\n   npm install -g npm\n   ```\n\n3. **Instale o LG webOS CLI**\n   ```powershell\n   npm install -g @webos-tools/ares-cli\n   ```\n\n4. **Verifique a instalação**\n   ```powershell\n   ares-cli --version\n   ```\n\n   Você deve ver algo como: `@webos-tools/ares-cli/X.X.X`\n\n### macOS\n\n1. **Abra o Terminal**\n   - Pressione Cmd + Space\n   - Digite: Terminal\n   - Pressione Enter\n\n2. **Instale o Homebrew (se não tiver)**\n   ```bash\n   /bin/bash -c \"$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)\"\n   ```\n\n3. **Instale o LG webOS CLI**\n   ```bash\n   npm install -g @webos-tools/ares-cli\n   ```\n\n4. **Verifique a instalação**\n   ```bash\n   ares-cli --version\n   ```\n\n### Linux (Ubuntu/Debian)\n\n1. **Abra o Terminal**\n   - Pressione Ctrl + Alt + T\n\n2. **Atualize o sistema**\n   ```bash\n   sudo apt update && sudo apt upgrade -y\n   ```\n\n3. **Instale o LG webOS CLI**\n   ```bash\n   sudo npm install -g @webos-tools/ares-cli\n   ```\n\n4. **Verifique a instalação**\n   ```bash\n   ares-cli --version\n   ```\n\n---\n\n## PARTE 2: Preparar a TV LG webOS\n\n### Habilitar o Modo Desenvolvedor\n\n1. **Ligue a TV LG webOS**\n\n2. **Vá para Configurações**\n   - Use o controle remoto\n   - Pressione o botão Home ou Menu\n   - Vá para: Configurações (ou Settings)\n\n3. **Encontre a opção de Desenvolvedor**\n   - Configurações > Sobre (ou About this TV)\n   - Procure por uma opção como:\n     - \"Developer Mode\"\n     - \"Modo Desenvolvedor\"\n     - \"Enable Developer Mode\"\n   - Alguns modelos de TV podem ter:\n     - Configurações > Informações da TV > Versão\n\n4. **Habilite o Modo Desenvolvedor**\n   - Selecione e ative a opção\n   - A TV pode pedir uma senha (geralmente: 0000)\n   - Reinicie a TV se necessário\n\n5. **Anote o IP da TV**\n   - Vá para: Configurações > Rede\n   - Você verá algo como: 192.168.1.XXX\n   - **Anote este IP** (você vai usar em breve)\n\n6. **Ative a conexão SSH (se disponível)**\n   - Alguns modelos pedem para habilitar SSH\n   - Procure em: Configurações > Desenvolvedores > SSH\n   - Se houver, marque para ativar\n\n---\n\n## PARTE 3: Conectar o PC à TV\n\n### Windows\n\n1. **Abra PowerShell como Administrador**\n\n2. **Vá para a pasta do projeto**\n   ```powershell\n   cd C:\\caminho\\para\\LG-WebOS-IPTV-App\\tv-app\n   ```\n\n3. **Adicione o dispositivo (TV) ao CLI**\n   ```powershell\n   ares-device-info --add --host 192.168.1.XXX --user root --password roap --name minha-tv\n   ```\n   \n   Substitua `192.168.1.XXX` pelo IP da sua TV\n\n4. **Verifique se foi adicionado**\n   ```powershell\n   ares-device-info --list\n   ```\n\n   Você deve ver `minha-tv` na lista\n\n### macOS / Linux\n\n1. **Abra o Terminal**\n\n2. **Vá para a pasta do projeto**\n   ```bash\n   cd ~/caminho/para/LG-WebOS-IPTV-App/tv-app\n   ```\n\n3. **Adicione o dispositivo (TV) ao CLI**\n   ```bash\n   ares-device-info --add --host 192.168.1.XXX --user root --password roap --name minha-tv\n   ```\n   \n   Substitua `192.168.1.XXX` pelo IP da sua TV\n\n4. **Verifique se foi adicionado**\n   ```bash\n   ares-device-info --list\n   ```\n\n---\n\n## PARTE 4: Build e Deploy do App\n\n### Passo 1: Instalar Dependências\n\n**Windows (PowerShell como Admin):**\n```powershell\ncd C:\\caminho\\para\\LG-WebOS-IPTV-App\\tv-app\nnpm install\n```\n\n**macOS / Linux:**\n```bash\ncd ~/caminho/para/LG-WebOS-IPTV-App/tv-app\nnpm install\n```\n\n### Passo 2: Testar Localmente\n\n```bash\nnpm run dev\n```\n\nAbra no navegador: `http://localhost:3000`\n\nTeste:\n- Navegação com setas do teclado\n- Busca\n- Importar uma playlist M3U\n- Player\n\nPressione Ctrl+C para parar\n\n### Passo 3: Build para Produção\n\n```bash\nnpm run build\n```\n\nIsso vai gerar uma pasta `dist/` com os arquivos otimizados\n\n### Passo 4: Empacotar para webOS\n\n**Windows:**\n```powershell\n.\\deploy.bat\n```\n\n**macOS / Linux:**\n```bash\nchmod +x deploy.sh\n./deploy.sh\n```\n\nIsso vai gerar um arquivo `.ipk` (exemplo: `com.tvstream.iptv-1.0.0.ipk`)\n\n### Passo 5: Instalar na TV\n\n**Windows:**\n```powershell\nares-install --device minha-tv com.tvstream.iptv*.ipk\n```\n\n**macOS / Linux:**\n```bash\nares-install --device minha-tv com.tvstream.iptv*.ipk\n```\n\nVocê verá algo como:\n```\nInstalling package com.tvstream.iptv-1.0.0.ipk...\nInstall successful\n```\n\n### Passo 6: Executar o App na TV\n\n**Opção 1: Manualmente**\n- Na TV, procure por \"TV Stream\" na lista de aplicativos\n- Selecione e pressione Enter\n\n**Opção 2: Pelo CLI**\n```bash\nares-launch --device minha-tv com.tvstream.iptv\n```\n\n---\n\n## PARTE 5: Troubleshooting\n\n### \"Device not found\"\n\n```bash\n# Verifique se a TV está na mesma rede\nping 192.168.1.XXX\n\n# Lista dispositivos adicionados\nares-device-info --list\n\n# Tente remover e adicionar novamente\nares-device-info --remove minha-tv\nares-device-info --add --host 192.168.1.XXX --user root --password roap --name minha-tv\n```\n\n### \"Connection refused\"\n\n1. Reinicie a TV\n2. Verifique se o Modo Desenvolvedor está ativado\n3. Verifique a senha (geralmente: `roap`)\n4. Teste a conexão SSH:\n   ```bash\n   ssh root@192.168.1.XXX\n   ```\n\n### \"Installation failed\"\n\n1. Verifique se o `.ipk` foi gerado corretamente\n2. Limpe builds anteriores:\n   ```bash\n   rm -rf dist/ *.ipk\n   npm run build\n   ```\n3. Tente novamente\n\n### App não aparece na TV\n\n1. Reinicie a TV\n2. Vá para: Aplicativos > Meus Aplicativos\n3. Procure por \"TV Stream\"\n4. Se não aparecer, reinstale:\n   ```bash\n   ares-install --device minha-tv -r com.tvstream.iptv\n   ares-install --device minha-tv com.tvstream.iptv*.ipk\n   ```\n\n---\n\n## PARTE 6: Debug e Logs\n\n### Ver logs em tempo real\n\n```bash\nares-inspect --device minha-tv com.tvstream.iptv\n```\n\nIsso abre uma janela com o console do navegador, similar ao F12 do Chrome.\n\n### Desinstalar o App\n\n```bash\nares-install --device minha-tv -r com.tvstream.iptv\n```\n\n### Ver apps instalados\n\n```bash\nares-ls --device minha-tv\n```\n\n---\n\n## RESUMO RÁPIDO DOS COMANDOS\n\n```bash\n# Instalar SDK\nnpm install -g @webos-tools/ares-cli\n\n# Adicionar TV\nares-device-info --add --host 192.168.1.XXX --user root --password roap --name minha-tv\n\n# Listar dispositivos\nares-device-info --list\n\n# Dentro da pasta tv-app:\nnpm install\nnpm run build\n./deploy.sh          # ou deploy.bat no Windows\n\n# Instalar na TV\nares-install --device minha-tv com.tvstream.iptv*.ipk\n\n# Executar\nares-launch --device minha-tv com.tvstream.iptv\n\n# Ver logs\nares-inspect --device minha-tv com.tvstream.iptv\n\n# Desinstalar\nares-install --device minha-tv -r com.tvstream.iptv\n```\n\n---\n\n## Próximas Etapas\n\nApós instalar com sucesso:\n\n1. Teste a navegação com o controle remoto\n2. Importe uma playlist M3U\n3. Teste o player\n4. Guarde o arquivo `.ipk` para reinstalações futuras\n5.
