# Guia de Deploy para LG webOS\n\n## 1. Pré-requisitos\n\n### Sistema Operacional\n- Linux, macOS ou Windows\n\n### Software Necessário\n- Node.js 16+ (https://nodejs.org)\n- npm (incluído com Node.js)\n- LG webOS SDK CLI\n\n### Hardware\n- TV LG com webOS 3.0 ou superior\n- Conectada à mesma rede do computador\n\n## 2. Instalação do LG webOS SDK\n\n### Windows, Mac e Linux\n\n```bash\n# Instalar globalmente\nnpm install -g @webos-tools/ares-cli\n\n# Verificar instalação\nares-cli --version\n```\n\n## 3. Preparar a TV\n\n### Habilitar o Modo Desenvolvedor\n\n1. Abra a TV\n2. Vá para **Configurações** > **Sobre**\n3. Procure por uma opção para habilitar \"Developer Mode\" ou \"Desenvolvedor\"\n4. Anote o **IP da TV** em **Configurações** > **Rede**\n\n### Adicionar Dispositivo ao CLI\n\n```bash\n# Conectar à TV (use o IP da sua TV)\nares-device-info --list\n\n# Adicionar novo dispositivo\nares-device-info --add --host <IP_DA_TV> --user root --password roap <NOME_DISPOSITIVO>\n\n# Exemplo:\nares-device-info --add --host 192.168.1.100 --user root --password roap minha-tv\n```\n\n## 4. Build e Empacotamento\n\n### Opção 1: Usar o Script de Deploy (Recomendado)\n\n**Linux/Mac:**\n```bash\ncd tv-app\nchmod +x deploy.sh\n./deploy.sh\n```\n\n**Windows:**\n```cmd\ncd tv-app\ndeploy.bat\n```\n\n### Opção 2: Manualmente\n\n```bash\ncd tv-app\n\n# 1. Instalar dependências\nnpm install\n\n# 2. Build da aplicação\nnpm run build\n\n# 3. Copiar manifesto\ncp appinfo.json dist/\n\n# 4. Empacotar\nares-package dist/\n\n# 5. Instalação\n# Use o comando gerado pelo script de deploy\n```\n\n## 5. Instalar na TV\n\n```bash\n# Instalação com nome do dispositivo\nares-install --device minha-tv com.tvstream.iptv*.ipk\n\n# Ou com IP direto\nares-install --device 192.168.1.100:22 com.tvstream.iptv*.ipk\n```\n\n## 6. Verificar Instalação\n\n```bash\n# Listar apps instalados\nares-ls --device minha-tv\n\n# Buscar by app ID\nares-ls --device minha-tv | grep tvstream\n```\n\n## 7. Debug e Teste\n\n### Ver logs da aplicação\n```bash\nares-launch --device minha-tv com.tvstream.iptv\nares-inspect --device minha-tv com.tvstream.iptv\n```\n\n### Modo preview em dev\n```bash\ncd tv-app\nnpm run preview\n\n# Abra http://localhost:4173 no navegador\n```\n\n## 8. Atualizar o App\n\n```bash\n# Fazer alterações\n# Rebuild\nnpm run build\ncp appinfo.json dist/\n\n# Desinstalar versão antiga (opcional)\nares-install --device minha-tv -r com.tvstream.iptv\n\n# Empacotar e instalar nova versão\nares-package dist/\nares-install --device minha-tv com.tvstream.iptv*.ipk\n```\n\n## 9. Desinstalar\n\n```bash\nares-install --device minha-tv -r com.tvstream.iptv\n```\n\n## 10. Troubleshooting\n\n### Erro: \"Device not found\"\n- Verifique se a TV está ligada\n- Confirme a conectividade de rede\n- Tente listar dispositivos: `ares-device-info --list`\n\n### Erro: \"Permission denied\"\n- Habilite o Developer Mode na TV\n- Reinicie a TV\n- Remova e adicione o dispositivo novamente\n\n### App não abre\n- Verifique se `appinfo.json` está correto\n- Confirme que `index.html` existe em `dist/`\n- Veja os logs com `ares-inspect`\n\n### Playlist não carrega\n- Teste a URL em um navegador desktop\n- Confirme que a TV tem acesso à internet\n- Verifique o formato M3U\n\n## 11. Variáveis de Ambiente\n\n### Para testes avançados\n\n```bash\n# Debug mode\nDEBUG=* ares-launch --device minha-tv com.tvstream.iptv\n\n# Output JSON\nares-device-info --list --format=json\n```\n\n## 12. Referências\n\n- [LG webOS SDK Docs](https://webostv.developer.lge.com/)\n- [ares-cli Documentation](https://github.com/webosose/ares-cli)\n- [webOS TV Development](https://webostv.developer.lge.com/develop/getting-started)\n\n## 13. Suporte\n\nSe encontrar problemas, consulte:\n1. Os logs da aplicação (`ares-inspect`)\n2. O console do navegador (F12)\n3. A documentação oficial do webOS SDK\n"
